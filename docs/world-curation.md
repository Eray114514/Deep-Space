# 正式宇宙选种记录

发行版的正式宇宙种子是 `NAVEMI-382`。玩家不负责生成或重构宇宙；种子是开发期内容筛选工具。

## 筛选方法

`tools/curate-worlds.js` 使用固定候选流 `DEEP-SPACE-CURATION-V1`，对 1,024 个可复现候选进行第一轮静态筛选。评分覆盖出生星系天体类型、前四颗行星差异、可登陆环境、双星、巨行星、卫星数量，以及邻近 18 个星系的类型覆盖。静态得分只负责淘汰，不直接决定胜者。

第二轮使用 `tools/capture-world-candidates.js` 在相同镜头和渲染条件下检查出生轨道、各类主行星、低空地形、落地点与飞船回看。最终候选为：

- `SORO-559`：天体丰富，但出生地表较平，第一印象偏弱。
- `IOKAHE-742`：出生群岛山地突出，但巨行星重复度高，B 型伴星导致部分轨道视图过曝。
- `NADALA-118`：山海落地点优秀，但主系统环境覆盖略少。
- `NAVEMI-382`：双星、近月、宜居海岸、毒性世界、气态与冰巨星，以及丰富卫星形成最完整的首个星系节奏。

因此选定 `NAVEMI-382`。更改正式种子必须重新运行静态筛选、同镜头视觉比较和完整浏览器游玩，不能从随机结果中直接挑选。
