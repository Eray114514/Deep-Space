## 如何读难度

| 等级 | 含义 | 选 agent 的建议 |
|---|---|---|
| 1 低 | 明确的整理、记录或机械操作 | 成本较低的 agent，按清单完成即可 |
| 2 较低 | 单一模块或已有工具的补齐、验证 | 普通编码 agent，要求读懂现有入口 |
| 3 中 | 几个模块联动，方案基本清楚 | 熟悉项目的 agent，保留针对性回归 |
| 4 高 | 涉及视觉、几何、性能或复杂状态，需要反复实测 | 较强 agent，并匹配图形/玩法/音频专长 |
| 5 很高 | 架构、数值或视觉方案容易返工，需要参考和实机证据 | 由相应领域负责人做完整闭环，优先保证上下文连续 |
