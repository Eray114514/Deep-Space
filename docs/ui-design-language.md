# 深空的 UI 视觉语言

2026-11-16 起，界面分成两套语言，互不混用。参考的是 Starfield：它的 HUD 是蓝色线稿，菜单却是中性的黑白灰，蓝色只作极少量的状态色，所以蓝色不会蔓延到所有界面。

## 两套语言

| | HUD（飞行 HUD、步行表盘、地表武器、触屏环、世界内标记） | 菜单与星图面板（标题卡、Hero、暂停、设置、教程、航线协议、星图面板） |
|---|---|---|
| 底 | 没有底板（步行表盘与触屏摇杆只留极浅中性暗晶底）。线条和字形直接压在画面上 | 不透明的中性炭灰实底 `--menu-plate`，主面板顶边白线 |
| 颜色 | 冷白 / 淡青描边（`--ship-cyan`），米白强调（`--ship-cream`），琥珀/红色只给过热与告警 | 黑白灰。暖色琥珀 `--menu-warn` 只用于性能提示、高风险星域与状态点 |
| 可读性 | 深色光晕 `--hud-halo`，静态线条下面垫一条更宽的深色描边（`staticStroke`），不用彩色外发光 | 实底保证对比，不需要光晕 |
| 选中 | — | 白底黑字的反相态（`.menu-cursor`、`.route-card.is-selected`、`.toolFilters button.active`） |
| 识别 | — | 四色品牌条 `.brand-stripe`（`--brand-1..4`），只出现在标题卡、Hero、暂停、航线协议、抵达标题 |

## 字体

- `--font-latin`：Barlow（OFL，自托管于 `assets/fonts/`），中文落到系统黑体。菜单正文、标题。
- `--font-hud`：Barlow Semi Condensed。HUD 读数、小号大写标签、按键。
- 不再使用等宽字体做装饰性标签；代码路径之类真正需要等宽的地方才用 Consolas。
- 字重以 500 / 600 为主。不用 200 / 250 这类细字重做标题，也不用 900 以上的粗字重。

## 构图

- 标题卡与 Hero 是同一个对象。Hero 左下角的卡片和加载卡一模一样（眉标、DEEP SPACE、进度条），菜单从进度条下方展开；页脚放副标题和按键提示。
- Hero 右下角是母星档案（`#hero-dossier`，数据来自 `StarMap.bodyDossier`），和左侧卡片对称，给画面补上世界里的内容，而不只是界面。窄于 900px 时隐藏。
- 飞行 HUD 两个下角对称：左边配电面板，右边护盾/船体两列分段竖条（与配电格子同一套单元格）、大号读数和一行状态（系统正常 / 船体受损 / 结构危急）。不画飞船俯视剪影。

## 动效

- 标题卡完全静态。`#loading` 和 `#hero-splash` 画同一张卡，加载结束时只有状态行从"加载中 · %"换成"点击进入"。
- 点击进入：卡片从屏幕中央滑到左下（FLIP，0.8s），闪屏底板淡出露出母星，菜单行、页脚、母星档案依次出现。
- 菜单与弹窗：选中条 0.16s 滑动，暂停面板 0.22s 从左侧滑入，图形设置（Hero 与暂停菜单均可打开）与航线协议弹窗平滑入场。悬停、筛选、配电切换和确认均有音效（`ui-sound` 事件 → `audio.playUi`，走独立总线，暂停与星图中也能响）。支持方向键、`1`/`2`、`Enter`/`Esc` 全键盘操作。
- 星图（`starmap.js` + `sysview.js`）：银河图与星系预览同留视口内。点选恒星进入星系预览时，银河相机沿对数距离曲线俯冲向目标恒星并交叉溶解至星系预览的环绕推近镜头（约 0.54s）；返回银河图时从当前检视恒星拉远回到邻域星图并保持焦点；点选行星时镜头靶心做轻量视差偏移，`Q` 重置视角平滑回正。面板统一为中性炭灰实底，筛选选中态与“设定航线”悬停态采用白底黑字反相，右侧资源格按挥发物/金属/稀有分类着色并与勘测特征栏紧凑排布。
- 航线协议（`#route-choice`）：两列架构化卡片（恒星跃迁折线轨迹图 / 弦界航道喉道示意图），当前选中或悬停项整卡反相为白底黑字并微幅抬升。
- HUD：`ShipHUD.syncVisibility` 监听 body 上的隐藏类（`hero-active`、`ui-walk`、`travel-cinematic`、`hide-hud`、`starmap-open`、`route-choice-active`）。每次回到驾驶状态都播放约 1.1s 的开机序列：闪烁 → 圆环和刻度描线 → 仪表行依次点亮 → 标签和侧面板擦入 → 配电格逐格亮起，船体数值从 0 计到当前值。离开时侧面板向中间收拢、整体淡出。
- 开机动画一律用 `animation-fill-mode: backwards`，结束后由 HUD 每帧写入的属性接管。
- 情境：配电面板 6 秒无操作后降到 58% 不透明度，操作或跃迁自动配电时恢复满亮；助推激活时标签提亮为米白；脉冲折叠时圆环微缩，燃料回充时读数呼吸；脉冲炮低电容变琥珀色；船体受损时船体竖条边框闪红，状态行按损伤程度变琥珀或红色；护盾顶格缓慢呼吸；脉冲燃料低于 30% 时脉冲标签呼吸闪烁。地表探索表盘（`walkdial.js`）、右下武器读数（`#surface-weapon`）、世界内目的地菱形标记与触屏环形控件统一采用 `Barlow Semi Condensed` 与无底板冷白/米白线稿语言。HUD 隐藏时跳过每帧 SVG 更新。
- 所有动效都有 `prefers-reduced-motion` 降级。
