# 深空优化路线图

更新：2026-09-30。本文维护跨批次目标、依赖和状态；B 的细节只在[云与大气计划](cloud-atmosphere-rewrite.md)维护。已撤销方案、逐轮调参和失败日志回 Git 历史查阅（精简前版本 `294c204`），不再与当前指令并列。仍有效的用户反馈、参考入口与采用决定必须保留链接，不能当作历史噪声删掉。

安排单次任务或切换 agent 时，见[未完成任务难度评估](remaining-work-difficulty.md)：细分难度和前置条件，执行按相互依赖的完整成果分组；不要求逐行停工汇报，也不复制本计划的完成状态。

## 共同目标与边界

- 写实、细腻、有尺度和探索吸引力的玩家画面。代码覆盖率、固定夹具和数值合同不能单独代替连续游玩验收。
- **WebGL 2 / GLSL 是唯一生产基准。** `legacy-render-pipeline.js` 与 GLSL 材质为实现载体；`?renderer=webgpu` 是兼容别名。2026-08-15 删除 WebGPU/TSL 线，原因是轨道云门控、大气闪烁和深度/合成错误未收敛。未来仅在用户重新决策后恢复，一次迁移一个子系统。
- 全量重构期间不处理宇宙锁，不为测试变绿刷新 lock。重构验收后按用户要求单独[重筛发布宇宙](world-curation.md)。确定性与稳定天体 ID 仍须保持。
- 画质优先；优化要有同机位质量/成本对照。实现清单不是扩展上限；各批次通过明确接口协作。
- 区分实证、推测和候选。参考项目的常数、一次截图或模型盲评都不能直接成为完成依据。

## C：地表景物、星环与星系

### 植被与材质

保留 `scatter.js` / `farflora.js` 的经典 InstancedMesh、逐实例风相位和发光植物。恢复可用不等于画质达标，先固定当前昼暮夜、地面/低空/远景基线。

- [ ] 树至少 3 级连贯 LOD，近处枝叶与发光植物协调，远景 proxy 匹配真实树种轮廓；按原决定以 ez-tree 为集成起点。
- [ ] 新增草地草型，读成连片草地；恶劣环境保留稀疏杂草。以形态、覆盖和运动验收，不只数实例。
- [ ] 岩石有层理、裂理、凹腔、法线/粗糙度；灌木和外星植物同步提升。
- [ ] 雪线由气候、坡度、受光和积雪条件调制，消除固定海拔横线；南北半球和不同恒星方向都成立，不写死世界轴“北坡”。
- [ ] 整体景物达到或超过 fable5 的地貌层次与自然融合，不能缩成只加岩石纹理。
- [ ] 步行、低飞、扫镜、LOD 切换无同步抖动或突然消失；真实密度与硬件预算同时验收。

验证：`test:vegetation`、`test:terrain`、`test:gameplay` 及截图/连续运动/性能。方案按证据选择，不机械搬用参考项目的 compute/TSL 架构。

### 星系观感

- [ ] 保留已记录的“最终母星单星”选择，放入最终重筛；本轮不擅自改变当前双星母星，B 仍须验证双星能力。
- [ ] 实看出生地与 18 邻居，核查双星印象来源，不以局部印象降低全银河双星率。
- [ ] 核查黑洞与普通目录系统的距离、尺度和导航；原 `<2 cells` 是候选隔离距离而非物理定律，不排斥黑洞自身俘获恒星。
- [ ] 保护 A 的 **6000 km** 母星，删除旧 700–1000 km 目标；记录正常飞行/助推/导航到达耗时，保留下降体验不拖长的目标（原 <90 s 必须注明起点与操作）。

### 星环

- [ ] 昼夜、掠射和正面有可信光照/透射，密集/稀薄环段、间隙与细结构可读。
- [ ] 行星投影到环、环投影到地表，随恒星与接收体变化，双星一致。
- [ ] 连续接近无硬圆盘感、排序错误或重复纹理，预览与真实世界一致。

先隔离光照、密度、几何贡献，再决定分段和厚度；增加分辨率不等于真实。验证 `test:sysview`、`test:astronomy:browser` 和生产连续画面。

## E：城市巨构、仓库与离港

绑定批次。先盘点 `artificial-sites.js`、`civilization.js` 与停泊/舱内流程，不用早期行号和尺寸冒称现状。以下目标不缩减：

- [ ] 核心城市 **30–50 km** 巨构群/灯光带，轨道和大气层可见，主体不可降落；配 N 个可降落、可步行航天港。
- [ ] 浮空城市 **8–15 km** 主体，玩家降落其中甲板区；弃用旧浮城 GLB，以模块化几何重做。
- [ ] 塔楼/桥/穹顶/支柱/天线等共享模块，近有材质设备细节、低飞有压迫感、远有整体轮廓，不能只是棋盘盒子。
- [ ] 尺度按文明规模与站点类型定义，轨道站 **90 km** 保留；巨构与航天港独立 LOD/裁剪，步行时仍保留可见主体。
- [ ] 开局第一人称位于母星轨道空间站仓库，按 F 电影化离港，舱门/运镜不拖沓，结束交回正常飞行。
- [ ] 仓库包含机库/甲板/走道/停机位；复用实际行走控制器，`walkdial.js` 是 HUD，不是移动/碰撞系统。
- [ ] 验证重复进入/离港、取消/暂停/失焦、输入移交、碰撞、资源预算与启动编译尖峰。

继承用户参考意见：spaceport-demo1 的离港与内部细节、demo2 外部造型、spacestation3 改作地表航天港。验证 `test:artificial`、`test:hero-handoff`、`test:gameplay`、`test:pointerlock`、`touchtest`，加轨道/低飞/步行连续画面。

## R：渲染基础与合流

已交付 `SceneRadianceState`、AgX、PBR 档案、船内外独立 PMREM/灯光域、非纯黑深空与曝光适应。2026-08-27 快照的 2K Balanced GPU timer 中位 legacy 5.99 ms / next 5.21 ms，只适用于当时机位，不能外推当前全场景。

B 提供介质结果，R 统一显示，不复制 LUT 或以全局提亮掩盖问题。`renderlook=legacy` 暂作回归对照，合流和用户确认后决定删除。验证 `test:render-look`、`test:render-look:perf`、`test:visual-smoke`，复核漏光、玻璃、日落、背阳面、反射及曝光切换。
