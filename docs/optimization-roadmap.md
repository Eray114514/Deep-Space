# 深空优化路线图

**2026-11-12 方向调整。** 用户实际游玩后判定当前主线不如线上版本。[状态盘点](reviews/state-audit-2026-11-12.md)用同路线实测确认：默认画质 2.5–23 帧，线上 72–174 帧，体积云是主因，云的画面也没有换来相称的效果。[第一轮救场](reviews/lite-clouds-2026-11-12.md)把默认云换成轻量通道（旧栈退到 `?clouds=legacy`），母星从 6000 km 缩到 1200 km，同路线回到 45–87 帧。此后以默认画质下的实际帧率和用户看到的画面作为验收依据；旧云栈的 F 阶段与 B4 进展只作历史，不再代表当前方向。当前待办见[未完成任务](remaining-work-difficulty.md)顶部。

更新于 2026-11-17。本文只维护全局目标、批次关系和各批次的一句话状态；执行细节在各专项文档，待办与难度在[未完成任务](remaining-work-difficulty.md)。2026-09 至 2026-11 的逐轮底层进展记录已删除，原文见提交 `2fe4b80` 的本文件、[渲染基础改进与交接](render-foundation-improvements.md)和 `baselines/` 下的各证据目录。

## 共同目标与边界

- 写实、细腻、有尺度和探索吸引力的玩家画面。代码覆盖率、固定夹具和数值合同不能单独代替连续游玩验收。
- **WebGL 2 / GLSL 是唯一生产基准。** `legacy-render-pipeline.js` 与 GLSL 材质为实现载体；`?renderer=webgpu` 是兼容别名。2026-08-15 删除 WebGPU/TSL 线，原因是轨道云门控、大气闪烁和深度/合成错误未收敛。未来仅在用户重新决策后恢复，一次迁移一个子系统。
- 全量重构期间不处理宇宙锁，不为测试变绿刷新 lock。重构验收后按用户要求单独[重筛发布宇宙](world-curation.md)。确定性与稳定天体 ID 仍须保持。
- 画质优先；优化要有同机位质量/成本对照。实现清单不是扩展上限；各批次通过明确接口协作。
- 区分实证、推测和候选。参考项目的常数、一次截图或模型盲评都不能直接成为完成依据。

## A：已交付与回归基线

A 验收的是地形与海洋的技术底座，不包括地貌观感；地形观感由 [T](planet-surface-rewrite.md) 重做。下面的数据按验收时的 **6000 km** 母星测得，母星已于 2026-11-12 缩到 **1200 km**，复测随 T 和云合流进行。验收时 relief/R 约 **0.284%**；地形噪声支持域、C1 山脊、连续坑形分别修复。地形/海面连续 LOD、局部高精度构建和近水细节已交付；海洋具备分波长吸收、浅滩/湿沙/泡沫、波面、玩家尾流、区域海况、异色/生物发光海洋及有限巨浪。

### 原生创作与变体

E 批次的人类工程按类型先做一个最高完成度的可游玩标杆。核心城市、浮城、地表航天港、轨道站及其他独立类型都采用这条顺序。各类型开工时由主控在《深空》仓库直接创作首件，集中打磨形体、功能布局、材质、照明和关键体验；Saltline 的材质库和道具库可以直接用。Hydrogen 验收集成、碰撞和控制状态、LOD 与性能。首件形成质量基准后，再用其模块、材质和设计规则扩成第二、第三个站点或更多变体，变体通过用途、轮廓、布局和动线形成区别。

### 空间站的画面与体验方向

以下提炼自用户曾用于生成旧样例的提示词，作为本项目原创空间站的创作方向。具体造型、设施取舍、控制和体验节奏由现有项目约束及首件设计决定，上方清单负责定义项目交付。

- **机库内景。** 第一人称从人员通道或高处平台望入封闭的巨型工业空间。飞船在中央停机区只占一小块，舱门和承重结构给出尺度。分层墙体、桁架、管线、维护走廊、设备和少量发光标识有各自用途。磨损的冷灰青金属、褪色警示黄和少量暖橙构成克制色调。少量强光照亮重点，暗部仍能读出结构。舱门开启有重量，外部光线逐步进入。
- **离港后回望。** 从站外看，刚才的巨型机库是站壳上的一处深凹模块。厚重的装甲和框架围住开口，坑底仍看得见灯光。远处有清楚的整体轮廓，中距离读得出塔、桥、环和功能分区，贴近能辨认面板、格栅、管道和航标。结构在顶部、底部、背面和缝隙里仍完整可信。材质与光照维持厚重、用过的工业质感。
- **连续可玩。** 从第一人称步行观察、登船、舱门开启到飞出回望应是连贯的体验。玩家可以环飞、贴近、飞远再回来，并尝试返航入库。实际可见结构提供碰撞，开放飞行空间以导航软引导提供方向感。飞船服务于港口的尺度与体验，创作重点放在机库和站体本身。

用机库内环顾、开门离港、回望、绕站和返航检验首件。复用项目的 HDR、材质和控制链，验证 `test:artificial`、`test:hero-handoff`、`test:gameplay`、`test:pointerlock`、`touchtest`，加轨道、低飞与步行连续画面。画面以 3A 游戏实机截图的可信度和完成度为标尺，首件按最终可用的标杆打磨。
