## 一、用户实拍照片

### G01 · 地面仰望的复杂天空
`photos/G01-ground-complex-sky-IMG_1896.jpg` · 2026-10-15 18:33（傍晚，太阳低）· 35 mm 等效 · 朝西南偏南

**画面内容**
- 左上一条又直又长的明亮云带：是凝结尾迹（航迹云）正在扩散，旁边有纤维状卷云。
- 中部、右侧：大片**高积云**（Altocumulus）——许多小云块挤在一起，单块边缘被低角度阳光照成金色，背阴面灰色；部分区域是絮状（floccus），部分连成片。
- 左下靠近地平线：**很细的波纹/鳞片**（高积云或卷积云的波状结构，即"鱼鳞天"）。
- 左中、地平线附近：更低、更暗的**层积云**团块，底部是深灰色。
- 至少三个高度层同时存在，彼此遮挡，颜色从金色到蓝灰，很丰富。

**对开发的启示**
- 天空里不应该只有"一种云"。中层的小云块 + 高层纤维云 + 低层暗色云团同时出现，才显得自然。
- 高积云单块很小（视角约 1°），排列有方向性，但不是规则网格。
- 低太阳角时，云块的亮边/暗面对比强，云块之间露出的天空是蓝色而不是灰白。

**对比用的应用视角**：`复合天空 · 地面仰望` 航点。

### A01 · 浓积云顶（长焦）
`photos/A01-cumulus-congestus-tops-IMG_0936.jpg` · 2026-09-17 06:52（清晨）· 168 mm 等效（长焦压缩）

- 上方：被阳光直射的**浓积云顶**，花椰菜状小鼓包轮廓清晰，亮面近白、带一点暖色。
- 下方：同一片云的下部/前景云处在阴影中，是大面积**蓝灰色**，几乎没有细节，只有柔和的体积起伏。
- 最上方：高层薄云（高层云/卷层云）和一条凝结尾迹。

**启示**：亮顶与阴影下体的明暗反差可以非常大；阴影中的云不是黑色而是被天空光照亮的蓝灰色。鼓包轮廓应该锐利而不是糊成雾。

### A02 · 太阳一侧的多层云系
`photos/A02-multilayer-sun-side-IMG_0932.jpg` · 2026-09-17 06:49 · 35 mm 等效 · 朝向太阳附近

从上到下大约五层：
1. 深蓝天空中的零星卷云；
2. 一层**波状高积云**（成排的小云块，"鱼鳞"状），太阳附近有彩虹色（虹彩/幻日类光学现象）；
3. 远处成条的高层薄云；
4. 地平线上一排远处的**积云顶**（像一列小山）；
5. 下方大片层积云/积云，云块投下阴影，底下的雾霾被太阳照成金色。

**启示**：这就是用户说的"大云下还有小云、高低不一"。高积云层和低层积云同时出现、互相遮挡，地平线附近有一排远处凸起的积云顶。

### D01–D10 · 飞机从巡航高度连续下降（约 40 分钟）
同一次航班（2026-09-17/18，机号 B-2002），从巡航高度一路下降到城市上空。拍摄时间依次为
23:54、23:55、23:57、00:10、00:13、00:21、00:22、00:22、00:30、00:34（相机时区）。
高度没有记录，以下高度均为根据画面的估计。

| 文件 | 估计高度 | 画面要点 | 对开发的启示 |
|---|---|---|---|
| `D01` | 巡航，约 10–11 km | 天空从天顶深蓝渐变到地平线淡白蓝；下方是连续的**层积云海**，非常白、对比很低，纹理是细碎的"棉花粒" | 高空天空的蓝要深；云海整体很亮，纹理细小，不是几公里大的"坨" |
| `D02` | 巡航 | 云海由大量小鼓包挤成，远处有暗色的低频起伏和裂缝，地平线发灰 | 云海表面有两级尺度：小鼓包（数百米）+ 更大的起伏/裂隙 |
| `D03` | 巡航 | 可见地平线弧度和白亮雾带；云海纹理随距离迅速变细、变平滑；远处有成排的条纹 | 远处纹理随距离变平滑并融进白色雾带；近处鼓包清晰 |
| `D04` | 下降初段 | 云海出现裂口，下方露出深色地面；靠近机翼处有一排排**波纹**；更低处是零散小积云 | 云海边缘破碎成波纹和小云块，并且下面还有更低的一层 |
| `D05` | 进入高层云下方 | 头顶是灰色的**高层云**遮挡阳光；下面是有缝隙的层积云和地面 | 存在"上面一层灰幕、下面一层云"的上下夹层结构 |
| `D06` | 中空 | 低太阳下的层积云/积云，远处有卷云 | 低太阳角下云块有明显明暗面 |
| `D07` | 中空 | 头顶卷云和多条凝结尾迹；下方大片**淡积云**（小而平底），地面上清楚可见云影；远处一条层积云的边 | 晴天积云很小、很多、底部平；**云影**投在地面上让画面有立体感 |
| `D08` | 中空 | 与 D07 几乎同一位置，稍后 3 秒；左侧有更大的云团伸出 | 大云团旁边散布着很多小云 |
| `D09` | 低空 | 头顶是高积云/卷积云，有絮状和片状；下面是农田 | 从下面看，中层云是带纹理的白色片状，夹着蓝天 |
| `D10` | 进近，约 1–2 km | 头顶一排排**积云/层积云**，底部平、灰，顶部亮白，排成行；下方是城市 | 低空仰望时，云底平且发灰，成行排列（云街） |

**整体规律（从这一组照片总结）**
1. 云海从上往下看是"亮白 + 细纹理"，对比低，远处融进白色雾带。
2. 不同高度的云同时存在：卷云/尾迹（最高）→ 高积云/高层云（中层）→ 层积云/积云（低层）。
3. 晴天积云多数很小，大小不一，平底，并在地面投下清晰阴影。
4. 云海的边缘不是一刀切，而是破碎成波纹、小云块，然后过渡到晴空。

## 四、怎样使用

1. 每次修改云的形态、光照或曝光后，用 `scripts/capture-refinement.mjs` 渲染相同航点。
2. 运行 `python scripts/reference-compare.py <截图目录>`，生成"应用截图 | 真实照片"并排对比图（输出在 `build/reference-compare/`），逐张看。
3. 对比时主要看：亮度与对比度、纹理尺度、云的种类和层次、远处雾带、云影、海面颜色——而不是追求和某一张照片一模一样。
