# 轨道云层视觉基准

`orbital-clouds-reference.png` 是用户提供的网络参考图，只用于开发与验收，
不得作为游戏运行时素材或对外宣传图片。

## 固定机位

- 16:9、隐藏 HUD，镜头位于云顶上方约 `0.35–0.55 R`。
- 斜视星球边缘，地平线位于画面上方约 20%，地表填满画面下部。
- 主恒星位于相机侧前方，使云顶有亮面、背光面和投影。
- 比较截图必须锁定世界种子、天气时刻、渲染 DPR 与自适应画质。

## 验收内容

- 视觉覆盖面积应与星球档案的 coverage 一致；覆盖率描述“有云区域”，不能
  通过整层低透明白膜伪造。
- 同一画面需同时存在千公里天气系统、锋面/云带、20–60 km 云团以及更细的
  云顶侵蚀，且无方格、经纬条带或重复贴图纹路。
- 积云和积雨云必须表现云底、云顶起伏、自阴影与地表投影；层云可以平展，但
  不能成为等高的实色球壳。
- 云间应能清楚看到有深浅变化的海洋和地形；星球边缘保持薄而连续的蓝色大气
  层，不能随镜头移动闪烁或整屏染蓝。
- 参考图用于构图、尺度、层次和光照对照，不要求复制其地理形状或逐像素匹配。

## 性能门槛

在 2560×1440、Ultra、硬件 WebGPU 的固定机位下记录稳定帧时间，并分别测试
云层开/关。开始页到飞船接管期间不得集中编译管线、上传地形块或重建体积渲染
目标；镜头运动时不得出现资源创建尖峰或大气合成失效。
