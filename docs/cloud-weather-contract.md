# B4 首族与天气接线契约

更新：2026-10-07（连续返工候选，未完成视觉/动态/性能验收）。覆盖 B4 的查询契约、生产天气迁移和局地高度接线；完成状态只写入[父计划](cloud-atmosphere-rewrite.md)。本页区分已实现的输入与后续形态/光学要求，不要求迁移整套 CPU 烘焙管线。

## 第一族：层积云

首个生产闭环采用 `stratocumulus`：浅层、胞状、有晴空孔隙，适合同时检查宏观云区、内部空隙、局地高度、近远一致性和云影。它比深对流和薄纤维云少一组采样难题，仍能暴露当前灰膜/平顶问题。不是把所有低云永久改成层积云。

`cloud-species.js` 的 2000 m 名义厚度、2200 m 水平特征和 30/km 消光已进入返工候选的层积云独立 band/密度参数，仍未获生产画面验收。候选普通云壳有 14 个独立云种参数，雾/夜光云尚缺独立生产路径；不能把参数接线称为可辨形态通过。这些尺度不按行星半径缩放；B4-08～10 仍须解决长切线采样、实际光源误差和成本。

## 已落地的查询边界

`src/cloud/cloud-environment.js` 提供两个无 Three/GPU 依赖的查询：

- `sampleCloudColumn(planet, localDirection)`：规范化体固方向，读取真实 `Planet.height(direction, fullMaxFreq)` 与平均液面。
- `sampleCloudEnvironment(planet, bodyLocalMeters, absoluteHours)`：在上述柱信息上添加径向高度、离地/离液面净空、绝对时刻。

`sampleCloudColumn` 已由 `planet-weather.js` 消费：一次烘焙固定 128×64 区域地形，提供真实地形/平均液面、区域海洋比例与导数输入；分辨率不随画质变化。局地云底已使用这个平滑地表和 LCL，细地形不会逐山尖顶起整片云。`CLOUD_ENVIRONMENT_VERSION` 只表示查询结构版本，不是天气内容版本。

| 字段/输入 | 唯一含义 |
|---|---|
| `bodyLocalMeters` | 以行星中心为原点、随行星自转的坐标，单位米；+Y 为本地极轴 |
| `direction` | 同一体固坐标中的单位方向，不含相机、天气风偏移 |
| `altitudeMeters` | `length(bodyLocalMeters) - R`，相对基准球面，可为负 |
| `terrainAltitudeMeters` | 真实地形相对 R 的高度，固定使用 canonical `fullMaxFreq`，不取当前可见网格 LOD |
| `seaAltitudeMeters` | 平均液面相对 R 的高度；无液体时为 `null`，不泄露旧 `-1e9` 哨兵 |
| `surfaceAltitudeMeters` | 有液体时取地形与平均液面的较高者，否则取地形；不含瞬时波峰 |
| `terrainClearanceMeters` / `surfaceClearanceMeters` | 径向高度减相应表面高度；保留负值，不把山体内部伪装成地面上 |
| `surfaceIsLiquid` | 此柱平均液面高于地形；是局地点分类，不等于天气模型需要的区域海洋比例 |
| `absoluteHours` / `absoluteSeconds` | 同一 `CelestialClock.hours` 及其 ×3600 换算；允许回溯，不取模、不积累帧 dt |

非有限坐标/时刻、零向量、无有效地形源会报错。不得悄悄回退为北极、零时刻或一颗默认行星。

坐标接入规则：宇宙坐标先用 `Planet.worldPositionToLocal`；相对行星的世界轴偏移用 `worldOffsetToLocal`。渲染浮动原点坐标先减去**同一原点**下的行星中心，再旋回体固坐标。CPU 在 JS double 中完成大坐标相减，GLSL 使用局部坐标/锚点；不要先把宇宙大数转成 float32 再相减。门户必须用目标行星的变换与时刻。

## 已接通的生产表示

有云行星由 `createPlanetWeatherField` 创建宏观天气所有者，调用 `weather-system.js` 的真实地形适配器。当前候选为 `weather-v9` / `production-synoptic:v6`，原生模型 v3。初始化以共享噪声、band 插值、形态及米制消光的 512 等面积柱校准一次天气势场偏置，判据为 `1-exp(-tau) >= 0.5`；不改光学系数，不逐帧重校。`opticalCalibration` 记录样本、偏置、测量值及 CPU 成本。生产 GPU 的独立 1024 柱复验仍是最终面积闸门；晴空连通性、投影画面和全部天气尚需验收。`makeCloudTextures` 不叠独立天气布局；无云行星使用轻量旧场，显式诊断 fixture 保留。

- **时间边界：** worker 候选按绝对小时重算原生生灭及当前地形响应，再插值相邻预测；间隔按角风速收紧并预取下一帧。角速率仍为 `windSpeed * 3600 / R * weatherSpeed`。低/中/高族宏观与微观平流倍率候选为 1/1.25/1.65，微观相位随天气提交及不可变预测时刻同步；族内高度风切变、动态一致性、跳时/回溯/重载和生命周期尚待验；不能称完整天气演化通过。
- **气候与照明：** `diurnalRangeK=0` 关闭伪太阳的日温差，纬度温度仍是内容近似；特殊云形成的原生 `nightSide` 已接查询小时的真实多星方向，CPU 与预测 worker 共享输入；雾/夜光云绘制和昼暮夜可见性尚未验收。B5 的实际双星场拥有照明，不能用 CPU 伪旋转太阳替代。
- **纹理：** 低/高图固定 256×128，覆盖编码仍为连续势场 `0.5 + potential/4`，插值后分别以 0.12/0.14 宽度解码。预测使用 Float 数据。当前 band v5 为 128×64×30 RGBA Float：前 16 层是云种，随后 8 层是云族内面积区间，随后 4 层打包整数候选遮罩，最后两层是高度包围及原始区域地形。仅插值前 24 层；加速数据取两预测的保守并集，地形保持静态。地表 texel 读取打包加速，体积另保留高度/整数候选纹理；遮罩不可线性插值。band 按北到南，公共 CPU 天气图按南到北；单个 band 数组 3.75 MiB，所有预测/快照须按此计数。云裁剪不能改用再次重采样的高天气图地形。
- **采样：** `weather-atlas.js` 统一像素中心、经度重复、纬度钳制和极点经度，并显式浮点插值。查询当前已提交小时可读共享 atlas；任意旧/未来小时不能读当前 atlas，须从同一原生模型重建。候选 band 高度包围必须包含零权重邻居的插值几何，不能据其权重为零而跳过高度。
- **所有权：** 预测 worker、云种数组纹理及三槽柱 render target（两个只读端点和一个预取） 均为本轮新增候选；共享纹理仍由 Planet 释放。fixture 重绑、两帧退役、context loss 释放/重建已改代码但未整体回归。CPU/GPU 必须分别实测 45/90 MiB 和 4 ms 门槛，不能沿用旧两图的静态字节数宣布资源预算通过。
- **形态参数：** 当前为 16×4 RGBA Float，前三行分别是尺度/起伏/消光、形态/家族/介质层/高度基准、最小垂直特征/平流倍率；第四行存 64 个固定噪声 CDF 样本。地表使用等价 uniform 数组，避免增加采样器。shape v10 用覆盖选择云区、面积区间选择云种，胞状/对流形态有显式空隙；不是视觉通过。`uCloudAdvectionPhase` 是绝对小时乘基础角风速，体积、地表、CPU 与预测共享。
- **高度与光学：** 当前 band 先存 LCL/雾相对原始区域地表的米制高度，再在查询点加地表高度；中/高云存相对 R 的绝对高度。积雨云仅基底随地表，顶界仍绝对，极高地形处保留最小厚度。参数 shape.w = 1 表示底/顶都相对地表，负数表示仅基底相对地表且绝对值为最小厚度，0 表示绝对 band。权重与 family amount 不含高度。云种四邻点显式 Float 插值，避免硬件过滤引入十米级高度差；保守加速包含物理角格、原始地形支持和整个预测间隔的旋转余量，不能把地形提前加进随风天气图，按物种参数生成点密度与消光。低/冰输出的 0.025/0.0006 只是返回值归一化尺度，最终每种 `/km` 系数均除以 1000；不是所有液态云统一 25/km。近景、地表/海面直射候选使用相同真实密度与完整太阳光程，已过局部数值对照；远景足迹、实际光源、反射、动态天气和成本尚未闭环。

## 最终内容输入与输出契约

2026-10-07 候选暂停边界见[断点交接](reviews/cloud-rework-checkpoint-2026-10-07.md)。近景光照缓存保存压缩光学厚度而非 R8 透射，组合回退使用独立标量接收后写入向量；缓存支持、更新期限和资源成本仍未通过。后续不能把这里的已接通输入当成首族/C1 验收。

以下包括尚未实现的目标，不能全部视为现行生产 API；当前能力以上节为准。

| 项目 | 约定与待实现边界 |
|---|---|
| 身份 | 内容身份包含 `galaxyId / systemId / bodyId`、seed 和生成参数；只用局部 `bodyId` 或对象引用作跨系统缓存键不够 |
| 内容版本 | 天气/云种/密度算法版本、地形/海平面/气候参数修订组成内容 revision；同 revision 同坐标同时间应可重建。查询结构版本、资源 generation 和内容 revision 分开 |
| 时间 | 所有消费者接同一绝对小时。`weatherSpeed` 只影响演化速率，不再把输入时钟乘一次。冻结、回溯、重载和跳时都显式传时间 |
| 帧一致性 | 一次绘制的云、远云、阴影、反射和局部玩法读同一内容 revision 与采样时刻；异步结果整代交换。不能一个更新了天气、另一个还拿旧纹理 |
| 地形与气候 | 使用真实柱数据；区域海洋比例/地形导数可平滑，但平滑尺度是内容参数，不能随画质变化。不得把合成地形代理当真实山脉 |
| 覆盖 | 大尺度 mask 定义云区和晴空，微观形态保留云区内孔隙；CPU `obstruction` 只是代理。最终 C5 另测积分透射和等面积遮挡 |
| 局地云底/云顶 | 最终 band 都用相对 R 的米制高度。LCL 表示起始空气上升到凝结所需的高度，必须明确起始空气面的高度后再转换；不能当成已是径向高度 |
| 高山/雾/高云 | 局地边界层的起始面与平滑尺度在 B4-03 定案，禁止直接用整球最高山抬云，亦禁止每个山尖都强制顶起整片云。雾随局地表面，高云用独立大气高度条件 |
| 密度/光学 | 分开记录无量纲凝结密度与 `extinctionPerMeter`；表内 `/km` 在边界除以 1000。云段 `tau = ∫ sigma_t ds`，步长单位米；不再由观察者或壳厚重定义消光 |
| 风 | 明确体固切向单位方向与 m/s 速率，或明确 m/s 速度向量。CPU 候选 `windVector.xyz` 是方向，另有 `.speed`；不能直接当米/秒速度。云平流位移与 B7 运动信息共用定义 |
| 太阳/照明 | 生产双星照明继续消费 B5 的实际恒星场。特殊云形成候选已读取查询时刻的真实多星方向；纬度温度仍为内容近似，雾/夜光云可见性和最终热力学响应待验 |
| 质量档 | 只选采样、过滤、步数和重建；不改内容 revision、天气布局、云底/云顶或消光。首族就做同点/同柱对照 |

不在这里增加独立 history。继续保留 B5 的 `C + Tc * Bair`；全屏 TAA、云占用深度与风运动补偿属于 B7。

| 地表/水面云影 | `surface-atmosphere.js` / `surface-clouds.js` 逐星直射候选使用共享云密度完整光程，移除 albedo/重复 glint 覆盖乘法 | 数值对照通过，真实画面、动态一致性、缓存与成本尚待验 |

## 固定测试点与验收边界

`tools/b4-weather-fixtures.js` 固定出生系的 0/2/4 号行星，12 个体固方向（赤道四向、两极、经度缝两侧、四个中纬点），时刻 0/9.5/48.5 h，径向高度 800/12000/300000 m，共 324 个查询。报告记录实际 body ID、seed、半径、地形与液面，防止把索引当稳定世界身份。

这些点是坐标/地形控制组，不承诺恰好位于层积云或每个天气系统。新场已接入，但晴空区、云区、锋面、眼/眼墙、副高、海陆交界的固定结构形态验收仍待补齐；保留本组控制，不能每轮搜索最容易通过的点替换失败点。生产密度已有晴空/非空/高云 readback，实际柱消光有 512 等面积方向和三个高度采样档的测量；首族形态与长切线光学 readback 仍须追加。

运行 `npm run test:b4:contract`：纯 Node 校验海底/液面/山体净空、绝对时钟、独立海平面变化和非法输入；浏览器用真实 Planet 的坐标变换/地形做 324 例，检查两种浮动原点与多次时间跳转后的可重现性。它不验证新天气已上线、GPU 密度/光学一致性或最终云形。

历史查询证据见 [B4-01 报告](baselines/b4-01-2026-09-26/report.json)。新天气用 `npm run test:b4:weather` 验证实际 GLSL 与 CPU/远云输入、极点/经度缝、晴空坏例、高云独立性和 fixture 重绑；生产矩阵与限制见[天气迁移交接](baselines/b4-weather-2026-09-26/README.md)。B5 历史归档保持不变。
