# 默认云与大气交付结论

2026-11-17，默认画质的云与大气视觉专项完成，转入维护。玩家已认可云的立体感，本轮实机反馈为「看起来确实是没啥毛病了」。

默认 WebGL 2 路径使用轻量体积云。云层沿球面延伸，飞船可接近并穿过云团。云影随日照落在地表，大气参与远景和行星边缘的合成。

- 远云。Hydrogen 对地平线和行星临边做了慢转与飞行对照。高画质下，2 km 平视时提前耗尽采样步数的像素由 10.91% 降至 0%。性能档仍有 40.27%，转头时可能漏掉一块碎云。[独立验收及逐帧证据](../../test-results/hydrogen-verify-2026-11-17c/REVIEW.md)
- 云影。提交 1cbce08 修复了约 50 km 高空飞行时地面云影闪烁。在海岸测试中，逐帧二阶亮度差超过阈值的计数由 2792 降至 998，关闭地面云影的对照为 892。
- 大气。提交 8ab7aa7 修复了参考地面球提前截断视线、在地平线画出蓝带的问题。第十九轮 Hydrogen 报告覆盖远云修复，早于这项改动。

完整多重散射场、水面的方向性云反射和低档采样仍有改进空间。当前观感已经达标，这些方向没有单独排期。全局 TAA、地表材质接收光照及多设备合流验证按各自路线维护。旧云栈可通过 `?clouds=legacy` 调出作对照。

第一至二十轮实验的完整记录可在 Git 提交 34338ec 的本文件中查阅。
