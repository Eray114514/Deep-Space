## 已查明与正在处理

- 原 S4 主星在所有距离实际使用体积路径，不能归咎于聚焦主星只画远云。关空气仍有缺陷，关云/零密度对照消除主要覆盖；直接检查了正常 HUD/post 的近景和整球原图。
- 天气 atlas 原先在 CPU 将连续势场阈值化为近似开关，再在 GPU 插值，轨道能看到网格阶梯。候选改为 R 编码 `0.5 + potential/4`，插值后解码；低/高过渡宽分别为 0.12/0.14。其余通道语义保持。体积、远云、原有云影和 CPU 查询已改用同一编码；只证明输入接线，不代表消费者柱透射闭环。
- RGBA8 硬件过滤的误差会被解码放大。共享 `weatherAtlasSample` 显式读取四邻点，在浮点中插值。402 个方向/旋转相位的远云最大误差由约 0.0367 降至 0.00519，维持原有 0.006 门槛；CPU 天气误差约 `2.7e-15`，晴空/非空/独立高云、fixture 重绑通过。见本地 `test-results/b4-rework/weather-gpu-manual-v2.log`；最终源码仍须重跑。
- 薄冰云原先保留消光，却因液态密度阈值跳过散射光源，是一个真实暗化问题。候选按实际消光决定是否有光源，不靠关闭冰云消除灰膜。
- 移除 `thick*3.2` 任意截断，并试验完整太阳光程、归一化 HG 和高阶散射近似。参数/效果尚未定案；独立散射能量和太阳光程误差证据未齐，不能称光照完成。
- 新增 `tools/b4mediumconvergencetest.js`：真实生产 main 的步数、jitter、几何与透射，对照 GPU 密度逐点读回、CPU 双精度积累的 1024/2048/4096 点参考。288 条三世界径向/掠射/云内射线中，旧候选最大遮挡误差约 0.0973，平均约 0.00085，判失败。200 m 水平上限、80 m 径向限制的下一候选最大误差约 0.04839、平均约 0.000334；参考加倍最大变化约 0.00327。单项通过不等于性能或画面通过；三档、屏幕足迹、太阳光程仍须补验。
- 空气的无云连续段延迟到下一个非空云样本，用共同 B5 积分合成；末尾无云段在 `Ljoint - Tc*Lclear` 中抵消。8 个实际深度/联合合成案例通过，最大误差约 0.000394。变密度空气、晨昏和正常前景仍须复查。

## 当前限制与接续要求

候选已改为 `production-bands.js` / `production-shape.js`：每个云种有独立 band、水平尺度、profile、形态与消光；16 项数据参与生成，其中 14 项接到普通云壳，雾/夜光云尚缺独立生产路径。**这不是 16 云种视觉完成**。实际查看的整球仍有噪点/块状痕迹，普通近景有过度平铺；形态、亮度和成本尚未合格。

## 深度、太阳光程与消费者复验

- 半分辨率云读取最近的全分辨率深度，比较的是两条不同射线，轨道下会错误裁掉低云。候选对连续行星表面重建四邻点的半径，再求当前云射线与该表面的交点；前景和不连续边缘仍保留拒绝。`b4depthfootprinttest.js` 用真实 D24 对数深度绘制球面，2852 条内部/掠射射线最大透明度误差约 0.000198、平均约 0.0000203；旧最近采样对照必须失败。仅此数值回归通过，不代替实际船体、植被、山体和动态边缘复验。
- 地表/海面逐星直射候选改为共享真实密度的太阳光程；移除在 albedo 上乘覆盖率、海面 glint 重复乘覆盖率。地表 PBR 触及 WebGL 16 个片元纹理上限，改以 uniform 数组保存云种参数，移除只用于加速的纹理，密度计算不变。水面天空反射仍是旧近似，尚未闭环；不能称消费者完成。
- 新 `b4sunbeamtest.js` 以 2048/4096 点 GPU 密度读回、独立双精度累积判断太阳透射，三世界 144 条地面出发的径向/斜射/近水平光程。原 12 段对数光程最大透射误差约 **0.9482，失败**。候选以 80 m 径向/200 m 水平步长完整积分，最大误差约 **0.00843**，参考加倍变化约 **0.000342**；原有 0.05 门槛内通过。体积、地表、无加速纹理三个消费者在这组光程的差异为 0。真实云内光源、夜光云、性能和动态太阳方向仍须补验。
- 上述消费者对照同时揭露跳空边界错误：零权重 texel 的高度仍参与插值，只统计非零权重高度会漏掉边界云。高度包围和候选 mask 改为：支持域任一点非空时，包含整个支持域的几何高度。`b4bandboundstest.js` 检查 113320 个插值高度/候选，含 28330 个零权重邻居案例，通过；太阳读回中原约 0.07817 的加速误差降为 0。

## 2026-10-01：实际柱面积校准与缓存成本

此前 p4 最后一次实际覆盖为 0.71680，距目标 0.64341 约 7.34 个百分点，失败。原因是宏观代理占区并不等于经过形态/消光后的生产不透明面积。候选将共享噪声图片抽到纯数据模块，CPU 点查询、初始化校准和 GPU 使用同一字节；初始化按 128×64 band 的插值支持，在 512 等面积方向积分生产形态/消光，仅调整一次天气势场偏置。它没有修改曝光、消光系数或运行时覆盖率。三世界初始化 CPU 校准约 0.43–0.57 秒/世界；不计首次共享噪声生成和整次冷启动。

独立 GPU 1024 柱、64/128/256 积分点复验通过（密度源码摘要 cbae9c376931，完整报告在 test-results/b4-optical-coverage/）：

| 时刻 | p0（目标 .64） | p2（目标 .72） | p4（目标 .64341） |
|---|---:|---:|---:|
| 0 h | .64160 | .74707 | .64844 |
| 24 h | .62402 | .74805 | .64844 |
| 48.5 h | .65234 | .72461 | .63477 |

所有样本保留超过 10% 的近透明柱，128/256 点的面积及平均透明度收敛满足原门槛。0 h 是初始化校准时刻，24/48.5 h 不参与校准。这里只通过实际面积子项，晴空连通性、投影观感、长切线、全部天气和 C5 整体尚未通过。

真实 GPU 计时否定了初始 128×128×256 四场径向太阳缓存直接接生产的候选：RTX 5080 Laptop 上累计约 3658 ms GPU 时间，个别单平面超过 11 ms，更新不能跟上天气。试验报告在 test-results/b4-sun-cache-perf/；不将脚本正常退出称为预算通过。后续候选用沿太阳光线剪切的网格消除逐层侧边界完整光程的重复成本，仍保留精确入射边界和 50 m 径向分辨率；径向场只允许在保守内域采样，外围夹持不作为有效结果。静态误差、固定物理评估点、更新时延和 GPU 成本仍须复验，尚未绑定生产。

光照缓存进一步归因：关闭复制、保留同一密度积分的诊断只需约 23.7 ms GPU 时间，证实主要成本在 3D 纹理逐层复制。改为二维 R16F 切片图集后，完整 128×128×256 四场累计约 38.3 ms，52 批中最大约 3.47 ms；固定物理点的 576 点回归仍为最大 0.04495，受控层最大 0.00822。图集只改变存储和查询，不降低物理采样精度；这不等于生产整帧或生命周期预算通过。

新 b4suncachemotiontest.js 用真实恒星方向和绝对时间天气，96×96×128 候选在静态 144 点最大误差约 0.02109；推进 0.003 h 后，p4 最大达 0.24977，推进 0.024 h 后最大 0.54558，**动态重投影失败**。p0/p2 在短时误差较小，不足以关闭跨天体更新。p4 的径向路径也失败，证明不能只用太阳角度阈值归因；天气经过当前地形的高度/权重变化须纳入缓存更新。缓存仍未绑定生产，后续须选择实测可行的更新/预测或其他表示，不使用静态过期缓存。

远景柱候选发现另一个具体几何问题：原来在外包络入口查询云柱，却在局部平均高度求交，二者是不同径向列，地形附近会错取云高/透射。代码候选改为逐层迭代自己的径向交点，并按实际前后关系合成液态/冰层，不假定冰层总在液态层前；取消平均高度的零海拔钳制。独立远景数值/实际原图复验仍待做，不能称硬孔洞已修好。

远景交点候选的独立解析闸门 b4columnparallaxtest.js 已通过：16 个变高度薄层/前景裁剪案例最大透明度误差约 0.0000488，关闭交点迭代的旧控制 16/16 失败。柱目标完成后释放烘焙材质和 uniforms 中的 CPU 快照引用；b4columnmaptest.js 对 DPR 1/1.25/2、普通目标与 cubemap 面 4 恢复通过。此处只验证对应生命周期片段，不代表全链路资源平台值。

普通包络下界改为包含实际区域最低表面，避免负海拔海面/谷地低云被固定 250 m 下界裁掉。b4cloudgeometrytest.js 同步按 Float atlas 的实际 scale 读高度，当前 11 个云 deck 顶点物理范围和已知坏哨兵控制通过，并产出三世界昼暮夜九张 S4 图（摘要 988db9b23893）。已打开当前 p0/p4 昼景原图；**视觉仍失败**：p0 有大片平铺白膜、粗硬孔洞，p4 仍有涂层与膨胀感。另强制完整柱缓存后打开 p0 原图，纹理颗粒减少，但白膜/孔洞仍在，HUD 约 1 FPS；不能将顶点测试正常退出写成画质或性能通过。

生产特殊云形成的夜侧输入已改接只读真实恒星历表：System 按查询小时求恒星/行星位置与实际 body orientation，CPU 查询读取同一方向集，worker 收到精确预测时刻的方向；有第二颗照明恒星时不能凭一颗伪太阳判夜侧。b4stellarweathertest.js 在六个生产天气世界、两颗恒星、五个小时、480 个方向通过，方向误差约 6.8e-16，功率差为 0，夜侧误差约 3.9e-16；查询不改变当前宇宙。纯 Node 双星/单星日夜控制也通过。雾和夜光云的生产绘制仍未完成，此项不代替特殊路径验收。

最新 smoke 在约 10.2 秒启动，实际非空画面、shader/runtime、输入与暂停通过。npm test 的非锁检查通过，旧宇宙锁比较仍失败，按全量重构例外不重写锁。新 volumeState 记录实际天气小时、提交小时、预测/柱准备状态及当前近远表示，避免用不存在的旧 uWeatherTime 默认 0 和未准备缓存进行错误验收。

地表光程成本的正常机位归因：保留同一 HUD/post/云/空气，临时只关闭地表云影积分，p0 S4 截图的 HUD 从约 1 FPS 提至约 19 FPS；白膜与硬孔洞仍在。这是瓶颈归因，关闭云影不能作为验收方案。候选恢复地表的保守 bounds/candidates，又在共享太阳光程中使用空球跳空：径向边界取同一角格最近占用高度 bins，角边界取经度平面与纬度圆锥的距离，不根据当前密度为零任意跳步。144 条实际太阳光程与无跳空控制最大差约 0.00000214，独立参考最大误差仍约 0.00817；密度查询总数 32397 降至 23337，约减少 28%。这组数据不证明任意长切线或整帧预算。

直接增加加速采样器的候选在实际地表材质超过 WebGL2 的 16 个 fragment samplers，失败；已改为 band v2 的附加切片打包，不增加地表纹理采样器。所有候选遮罩/包围在 64/128/256 宽度的 CPU 打包对照通过，地表与体积透射对照仍一致；完整源码启动的 p0 S4 无 shader/runtime 错误。但当前原图仍有白膜/颗粒，HUD 约 1 FPS，且该次柱缓存尚未准备完成；**视觉与性能仍失败**。stats 的历史 averageFps 约 103 不能替代当前机位帧时间，后续验收须用稳定窗口的实际 frame/GPU 计时。

## 2026-10-02：高度基准与当前候选

当前内容标识为 weather-v9 / production-synoptic:v6，band v4。低云之前把地表高度加进天气 band，再随天气网格插值，仍会平滑山峰并让云底沉到局地 LCL 以下；现在只插值 AGL，查询点再加原始区域地形。中/高云保持绝对高度并裁掉山体内部，积雨云只抬基底、保留绝对顶界。全壳保守上界同步扩充，母星候选约 27.16 km。b4heightdatumtest 的 112 个高度边界、61440 个经度缝/极点/预测旋转地形支持点通过；加速用完整物理角格和预测旋转余量，不把整球最高山当实际云底。

云种纹理的硬件插值还造成最大约 10.76 m 高度差；改为显式四邻点 Float 插值后，三世界 3075 点地形误差仍为 .02978 m、AGL 最大差 .01606 m，通过原 .1 m 门槛。实际太阳光程 144 例当前独立参考加倍差 .0002275，光程最大差 .01026，地表/体积差 0，跳空控制 .0001167；查询 27238 对照 42533。初始 GPU 覆盖面积和旧密度缓存证据须按新密度重新验证。

近景光照候选已接三个不可变预测槽、四场 R8 透射缓存，完成场才采样，越界/过期仍走完整光程；此前静态 576 点和动态 .003 h/720 点分别在 .04509/.04086 最大透射误差内。它们是接线前的旧密度局部结果，不能继承到新高度基准，更未证明所有双星、移动支持或帧预算。近景实际准备状态可读回，但当前原图仍失败：Sc 云下出现云团/孔隙，云内和所谓“Sc 上方”仍灰白，后者可能处于其他云族内，不得叫全云层上方通过。普通远景缓存即使完成，整球仍白膜与硬孔洞。

近景分位积分改为沿递增光程累计空气传输，避免每个分位点重复从相机积分同一段；8 个受控 B5 生产合成案例最大误差 .0003931 通过，真实变密度/晨昏源仍待独立参考。原图 HUD 约 6 FPS，不能把改善称为预算通过。

新增地表光程候选 cloud-surface-shadow-pass：复用 composer 的当前不透明深度目标，在四分之一宽高网格计算逐星完整光程，再按深度匹配重建；复用已有采样器，远端/不同相机仍走原查询。实际绑定成立，正常 S4 约 3 FPS，分段 GPU 光程候选中位约 9.16 ms，后续 composer 中位约 368.61 ms，明显失败。误差探针最初读取被后处理清空的深度，随后发现自定义探针 shader 未编译；空样本/无 console error 均不构成验证。必须检查程序链接、GL 错误、非空样本及当前帧深度所有权后再判断误差。四组返工仍均未关闭，尚未提交实现。

当前 AGL/显式插值源码的 9.5 h GPU 覆盖复验（摘要 86ed0d057418，1024 等面积柱）通过：p0 .65137、p2 .73047、p4 .64746；近透明柱 .23828/.17773/.25，128/256 收敛通过。光学面积是局部闸门，不替代投影图和晴空连通性。屏幕光程探针修复 shader 函数名和 float/int 类型错误，并在当前帧深度有效期间读回；322 个实际不透明采样点均有缓存支持，远景单点透射最大差约 .999997、平均 .20179。此处所有点足迹超过 50 m，远景尚缺足迹积分参考，不能沿用单点闸门宣称通过；近景仍须另测。

10 月 2 日补充归因：Surface cache 的深度权重改为相对最小差归一化，避免隐藏地形片元的共同深度差下溢。原生 Sc 整球实际材质/屏幕缓存绑定均可读回；该机位 RenderPass 中位从约 430.41 ms 降到 2.35 ms。换另一个机位后仍约 126.79 ms，逐 draw 证实主要是远处 planet-1 的材质，不能把单机位改善外推为整帧通过。当前候选增加保守深度下采样、异星遮挡成本裁剪（深度只在主不透明 pass 消费，与目标写入分开）及纯缓存远景编译变体；这些新项尚待当前源码验证，不提前列为通过。

远景射线足迹已在所有 discard 之前计算；实际 S4 98185 个非空片元足迹约 20.80–30.10 km，均大于原有 2.4 km 缓存阈值，且实际 far shader 的 uColumnsReady 为 1。分离编译的纯缓存变体仅在双预测完成且全屏保守足迹下界超过原阈值时选择；42336 个视角/宽高/边缘有限差分验证下界保守。远景约 65 ms 的剩余成本仍在归因，尚未证明该变体效果/成本。

校正机位术语：v12 原生 Sc 的相对参考球半径高度是云下约 0 m、云内约 899.6 m、Sc 上方约 3887.8 m；约 2548/3448/6436 m 是到海底地形的距离，不能当作绝对云高或距海面高度。当前天气场海面约 -57.19 m，不能误判为地形编码仍错了 2.5 km。npm test 当前 126 模块和非宇宙锁套件通过，锁比较仍为已知重构差异（1a50259… → e7f8096…）；没有重写锁，也不写成整体 npm test 通过。

纯缓存远景变体的隔离 GPU 成本已测：同机位 VolumetricPass 中位从约 65.71 ms 降到 .834 ms，原图仍存在灰膜与硬孔洞；这只证明代码分离的成本收益，不代表画质通过。当前游戏源码已按保守足迹条件选择变体，热补丁结果仍须由干净重载/数值等价/运动复验支撑。地表异星深度裁剪正在干净重载验证，主目标暂未完成。

干净重载的异星深度候选还没有达到预期：当前冷场 RenderPass 中位约 161.66 ms（波动 111–428 ms），VolumetricPass 约 84.03 ms，列预测尚未完成，不能把之前热补丁的稳定成本套进启动过程。继续修复每个 PBR/glint 分支重复计算同一恒星云透射的问题：在 fragment 的 logdepth 写入后按真实恒星顺序每星计算一次，PBR 只读对应结果。此候选尚待正确性、实际光源选择和成本复验。异星遮挡暂复用现有 transport 采样器，避免近景地形加阴影后超过 WebGL2 最低 16 槽。

后续已将主相机中实际有云的全部地表消费者接到同一屏幕光程目标，按天体 ID 与深度重建；主相机材质编译时移除逐片元完整光程，独立相机保留物理查询。16 个实际 GLSL 受控案例通过，包括异星 ID 拒绝、隐藏地形、双星只各算一次，以及无效邻点造成的 `0 × Infinity` 坏例。干净重载的 1600×900 正常场景、45 帧 GPU 采样中，RenderPass 中位约 1.864 ms、屏幕光程约 19.847 ms、尚未准备远景柱的 VolumetricPass 约 86.869 ms；这仍是启动/整帧成本失败，不能写成性能达标。真实远景阴影仍须与足迹积分参考比较，受控案例不代替该项。

云上采样曾用透明度相似权重排斥邻点，使轮廓锁到低分辨率格子；改为按不透明深度筛选的双线性重建。`b4upsampletest.js` 的真实生产合成 shader 在 DPR 1/1.25、线性信号及两像素细前景下，最大 RGB 差约 4.77e-8、前景污染为 0；最近邻坏例分别约 .140625/2.8125。正常整球原图仍有白膜/硬孔洞，不把重建修复写成首族视觉通过。
