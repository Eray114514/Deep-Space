## 数值与 GPU 回归

`npm run test:stage-b` 包含 `atmospherequadraturetest.js`；`npm run test:stage-b:gpu` 执行生产 GLSL 的积分段、LUT 采样、云密度与逐星光照，不使用测试专用密度替身。

- 独立参考为双精度、32,768 段 Simpson 积分，并有垂直指数密度解析式的坏例控制；三种半径/温度/profile，覆盖天顶、低斜角、掠地、日落太阳路径、轨道切线和反向垂直路径。
- 气柱误差定义为 `abs(actual-reference)/max(reference,100 m)`，阈值：视线 2%、太阳 LUT/插值 4%。因此小信号区容许绝对误差分别为 2 m / 4 m；这不是相对误差在接近零时仍受控的承诺。CPU 最大视线误差 **0.9165%**、LUT 离网格插值 **1.6155%**；GPU 对应夹具最大 **0.9158% / 0.4332%**。两套 LUT 采样点集不同，不能比较二者大小判断 CPU/GPU 优劣。
- 100 km 垂直 Mie 柱解析值 1200 m：旧 20 步等距视线约 632.38 m；新 GLSL 约 **1192.77 m**，GPU LUT 约 **1195.94 m**。旧算法会被新阈值拒绝。
- 云场夹具使用受控非空覆盖和生产 3D 噪声；30/56/93 km 三种厚度，每种 4096 个世界点，三个相机高度。每种包含 2478 个密度 >0.01 的点及 1603 个 <0.001 的点；相机间最大差 **0**。重新注入旧高度映射后最大差 **1**，证明能抓住原缺陷。此夹具不证明生产云的覆盖率或全部质量档的积分误差。
- 实际 `Planet.setStellarLights()` 接线后的双星主次交换读回一致；单星全食直射 RGB 为 **0/0/0**；未被遮挡的伴星为正，移除被遮挡主星不改变结果；换单星无残留伴星能量。
- 12 次不同 profile 的真实 WebGL 上传，纹理计数增量 `1,2,3,4,4,…,4`；dispose 后回到 0。另有 CPU 重访/共享/释放次数测试。这证明 LUT 资源上界，不证明全游戏显存、context restore 或新云纹理上传预算。

硬件：Chrome 153.0.8010.50、RTX 5080 Laptop / ANGLE D3D11 / WebGL2。GPU 与玩家报告的运行时源码摘要均为 `55337106e284cb11…`。GPU 报告：`test-results/stage-b-foundation/report.json`，含完整源码与验证器摘要；原始报告和截图是可再生成的本机产物，未作为大文件提交。

## 下一位执行者必须保留的边界

1. **气柱求积通过不等于物理散射完成。** `discWeight`、`discExtinctionWeight`、外缘权重、相机高度曝光及经验间接光仍在；先对最终线性 RGB 做独立高精度参考，再替换补偿项。不可把本次结果改写成完整 B5 PASS。
2. **云空气合成仍是优先阻塞。** 目前仍为 `cloudRGB + (1-cloudAlpha)*wholeAtmosphereBackground`。需定义沿路径的分段散射/透射，证明云前空气不会被错误压掉、云辐射正确经过前方空气；仅交换 pass 顺序不够。先做晴空、单团、薄层、厚云与前后几何夹具，再扩云种/最终调色。
3. **局部直射已修，完整多星遮挡未关闭。** 生产仍选一个主要遮挡体、共享一个恒星角半径；多遮挡体和只遮伴星的真实天体选择须扩展并测试。新测试证明给定球形遮挡体的逐星方向处理，不证明选择器已覆盖所有双星几何。经验云环境光不等于天空辐照闭环。
4. **世界密度已固定，生产天气尚未统一。** 新 CPU weather/species/occupancy 仍未接入；全局云底、`sigma=3.80/thick`、`thick*3.2` 长路径截断、观察高度白色上限仍是后续审查点。不可恢复相机依赖来修构图，也不可用新 CPU 覆盖率充当生产云的结果。
5. **资源和运动验收仍有界。** 云管理器的真实 WebGL 分帧上传、取消/恢复、跨星/门户压力测试未完成；运动诊断是同姿态确定性，上传钩子测 CPU 提交而非 GPU 耗时。新采样与逐点天气/双星增加了计算量，后续在最终链上测全帧预算，不以本次短窗口 FPS 声称性能闭合。
