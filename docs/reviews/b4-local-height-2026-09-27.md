# B4 局地高度与光学诊断（2026-09-27）

本页记录一组已接入的生产改动和**未通过的验收**，不表示 B4 完成。权威进度见[批次 B](../cloud-atmosphere-rewrite.md)，实施约束见[阶段 4](../cloud-phase4-volume-march.md)。

**后续更正：** 本报告漏掉了 p0 昼/夜 S4 的白色放射尖刺，用户指出后已定位并修复：无海洋卫星的海面哨兵污染云高范围，另有 Canvas 对天气数据的透明度加工。下面的数字保留为 `61bf9b97614f` 历史测量；[当前几何/数据修复及复测](../baselines/b4-cloud-geometry-2026-09-27/README.md)取代其当前状态含义，B4 仍未关闭。

## 已接入

- 区域地形采用真实行星高度/平均液面，静止表面通道与随风平流的 LCL 分开采样。低云的径向底高随局地表面、LCL 与小幅扰动变化，厚度随天气变化；高云另有 8.5–14.5 km 高度，不再把整球包络视为处处有云。母星体积包络约 0.25–20.42 km，包络上限只为不裁掉可能的高地低云。
- 体积低/高云的单位凝结量消光分别为 0.025/0.0006 m⁻¹，摆脱旧 `3.80 / thick` 对现行生产层的尺度依赖。旧诊断 fixture 仍走原路径。局地云去掉旧 powder 对源辐射的额外暗化；B5 的空气/云联合积分未改。
- 远景低/高云顶点随局地高度调整，云内玩法查询改用同一 atlas 解码地表与 LCL；fixture 切换时重绑高度模式与纹理。玩法密度仍是轻量近似，**不是**与体积逐点相同的消光。

## 数值与画面证据

`npm run test:b4:weather` 的 402 个方向/相位包括两极与经度缝。低图 GPU/CPU 最大通道差约 0.00262，远云 helper 约 0.00226；局地地表/LCL/云底 GPU 对照最大差约 **95.82 m**。高图 G 在全地形范围内只有 8 位，精度不足以为更细的 C4 地形位移背书。切换晴空 fixture 再恢复生产的高度模式、天气图与降水门控已做回归。[本次证据归档](../baselines/b4-local-2026-09-27/README.md)绑定源码摘要 `61bf9b97614f`。

`npm run test:b4:optical` 在三颗生产行星各取 512 个等面积方向，沿径向用 64/128/256 点积分**实际 GLSL 消光**；256 点的遮挡面积（柱遮挡 ≥ 0.5）与内容目标如下：

| 行星 | 内容目标 | 实际遮挡 | 严格晴空（遮挡 < 0.05） | 128→256 平均逐柱差 |
|---|---:|---:|---:|---:|
| p0 | 0.640 | 0.680 | 0.221 | 0.00561 |
| p2 | 0.720 | 0.652 | 0.244 | 0.00749 |
| p4 | 0.643 | 0.709 | 0.227 | 0.00476 |

这是最终介质的**径向柱**统计，不是模型代理覆盖率，也不是 S3/S4 斜视光程的收敛证明。个别柱 128→256 差最大仍可达约 0.28；p2/p4 距内容目标约 7–8 个百分点。不能据此关闭 C5。

同一正常 HUD/post 玩家机位的 RTX 5080 Laptop GPU 试测（1280×720 CSS，实际 1600×900，ultra，2.5 秒/组合）使用 `npm run test:b4:perf`。三次采样中云上约 120–137→89–92 FPS、整球约 138–139→60–62 FPS（关→开），云内约 120–136→115–136 FPS；最新整球开云的 p95 帧时约 16.8 ms。场景顺序、LOD 暖机和短采样仍影响这些数字；它们只定位开销，**不是** 2K 预算达标证明。现行源码已重采[63 机位/189 张玩家对照与上下连续帧](../baselines/b4-local-2026-09-27/matrix.png)，不是沿用旧天气迁移截图。目视仍有平展灰/白云顶、云内层次不足；云上向下看的部分灰色在关云图中仍存在，应归因于大气/地表而非全归咎于云。

## 否决的尝试和接续

- 直接移除 `thick * 3.2` 长光程裁剪，穿云机位一度约 1 FPS；临时自适应步长虽改善云内，却让云上机位出现约 3 FPS 尖峰。两版均已撤回。接续者必须同时设计保守跳空、薄层/长切线采样、尾部透射误差界和真实 GPU 预算，不能单独删截断。
- 加入公里级细胞噪声能让近景开孔，但 128→256 柱积分平均误差从约 0.005–0.007 升到 0.013–0.016，最大可超过 0.5，并出现条纹/闪烁。已撤回。真正的层积云胞状孔隙要与采样策略一起落地。
- 保守高度空段先于 3D 雕刻排除，512 柱的最终消光逐值与原实现相同。另修正从不透明地表内部出发的射线会错误采样行星背面云壳：`test:full` 的 SwiftShader gameplay 曾在登船后的测试起飞长时间停在 `takeoff`，关云对照可越过该处；加内部遮挡后同一路径已能到达飞行和后续操作。完整 `test:full` 仍在 gameplay 的暂停菜单点击上超时，不能记作通过。该软件 GPU 的菜单超时与生产硬件玩家帧时不可混为一谈。
- 现行太阳自阴影仍为短光程三点近似，远景 alpha/地面云影/水面反射也未消费同一柱光学；天气仍是 epoch 0 快照刚性平流。优先完成首族形态、斜视高样本参考和跨消费者光学，再扩 16 云种。绝不能把此轮的两层通用 band 说成全云种已实现。

复现：`npm run test:b4:weather`、`npm run test:b4:optical`、`npm run test:b4:perf`，玩家画面用 `B0_PROBE=1` 和 `STAGE_B_PHASE=B4LOCAL` 运行 `node tools/b0baselinetest.js`。正式 B4 收尾仍需完整三世界昼暮夜矩阵、连续飞行、C1/C4/C5 与用户实机审美验收。
