AF/S9 · GRAPHICS SETUP

启用独立显卡

  1. 01
    打开图形性能设置

    Win11：设置 → 游戏 → 游戏模式 → 显示卡，点“添加桌面应用”；或按 Win 搜索“图形设置”直达。Win10：设置 → 系统 → 显示 → 图形设置。

  2. 02
    找到浏览器的 exe 文件

    右键浏览器桌面快捷方式 → “打开文件所在位置”，资源管理器会跳转到 exe 所在目录。常见路径：

    • EdgeC:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
    • ChromeC:\Program Files\Google\Chrome\Application\chrome.exe
    • FirefoxC:\Program Files\Mozilla Firefox\firefox.exe
  3. 03
    设为“高性能”并重启浏览器

    在列表中点选刚添加的浏览器条目 → 选项 → 选“高性能” → 保存。完全关闭浏览器（含后台进程）后重新打开，刷新本页即可启用独显。

本作已对低性能设备自动降负载以保持流畅；启用独显后刷新本页即可获得完整画质。
